## Опис системи

Система являє собою термінал для PowerShell із підтримкою таких можливостей:
- налаштування кольорів синтаксичних конструкцій;
- налаштування розміру та фону вікна;
- виконання команд PowerShell і зовнішніх виконуваних файлів;
- робота в декількох вікнах через вкладки або розділення екрана (Split View).

## Виконані лабораторні роботи

- **Лабораторна робота № 1.** *Системи контролю версій. Розподілена система контролю версій «Git»* — створення репозиторію, робота з комітами, гілками, злиттям, тегами та віддаленим репозиторієм.
- **Лабораторна робота № 2.** *Основи проєктування* — діаграма варіантів використання, сценарії, діаграма класів, проєктування структури бази даних (`CommandHistory`, `TerminalSettings`) та реалізація шаблону `Repository`.
- **Лабораторна робота № 3.** *Поширення архітектури* — діаграма розгортання, діаграма компонентів, діаграми послідовностей та базова реалізація взаємодії модулів терміналу.
